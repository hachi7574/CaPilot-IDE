# CaPilot IDE Documentation

CaPilot IDE is a local AI coding workspace centered on interactive terminal sessions, file editing, Git, and ESP device control.

## Quick Start

```bash
pnpm install
pnpm tauri dev
pnpm tauri build
cd src-tauri && cargo test
```

Linux system dependencies: `libwebkit2gtk-4.1-dev librsvg2-dev libgtk-3-dev libsoup-3.0-dev libjavascriptcoregtk-4.1-dev`.
