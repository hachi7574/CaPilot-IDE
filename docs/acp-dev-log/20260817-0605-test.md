### F **可达性 F1 — FAIL → DEF-006（blocker Phase2）**
用户如何启动 `acp:opencode`？

| 入口 | 行为 | 能否 ACP |
| --- | --- | --- |
| 项目 `+` / `TerminalTemplatePicker` | `TermTemplate.runtime` 联合类型 **仅** bash/claude/codex/dsh/pi；**无** acp | ❌ |
| Composer 无 tab 时 Enter | `spawnAgent()` **默认 `claude`** | ❌ |
| Ctrl+T | `resolveCtrlTRuntime`：可用 id 含 list 全部（含 `acp:opencode`）——**仅当** Settings 把 Ctrl+T 设为该 id | ⚠️ 隐式旁路 |
| Settings → Ctrl+T 列表 | `runtimes.filter(available)` **会列出** `OpenCode (ACP)` | ⚠️ 非主路径、无说明 |
| 侧栏右键「切换 runtime」 | `agent_switch_runtime`；**后端 Phase1 拒绝** to/from ACP | ❌ 死路 |
| Onboarding | `spawnAgent()` 默认 claude | ❌ |

**结论：** Phase2 DoD「UI 完成 spawn→…」与 §12 **F1**（选择器可见并可开 ACP 会话）**未满足**。  
`runtime_list_available` 后端已有 `acp:opencode`，但 **主新建终端 UX 未接入**；用户几乎必然无法从正常 `+` 菜单开出 ACP tab。  
Ctrl+T 设置是唯一 realist 路径，但：
1. 非验收主路径；
2. 会把全局 Ctrl+T 默认从 claude 改成 ACP；
3. 文档/UI 未指引。

### G Stop / turnActive — PASS with note（minor，不单开 blocker）

- 若乐观路径失败/竞态，Stop 可能不出现；Esc 仍调 `cancelAcpTurn`（不依赖 turnActive）——缓解。
- 记 **DEF-007 minor**（建议 Host prompt 开始 emit `status: running`）。
