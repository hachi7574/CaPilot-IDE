# LUCY HTML UI 风格指南

> **用途**：本文件是一份"可直接投喂给 AI 的界面风格规范"。把本文件完整粘贴给任何能生成 HTML/CSS 的 AI（Cursor / Trae / Claude / Copilot），并要求它"按此风格生成 XX 界面"，即可产出同风格的页面。
>
> **风格名称**：`8-bit Pixel × Apple Smooth` —— 复古像素质感 × 现代苹果动效的暗色科技界面。
>
> **参考实现**：仓库 `docs/` 下所有 `<!-- Generated by Trae Work -->` 的 HTML 文档（PRD、roadmap、phase overview、research report）。

---

## 1. 一句话风格定义

**近黑蓝底的暗色科技风**：`#07090F` 类深底，**单一紫色强调系**（主 `#8B5CF6`，辅 `#A78BFA`/`#C4B5FD`，同属紫系，**无橙色、无青色**）；状态色只保留绿/黄/红三色；所有边框用 `2px` 实线、交互带 `4px 4px 0` 硬阴影；像素字体（Silkscreen）负责小标签和编号、科技感字体（Tektur / PixelifySans）负责标题、等宽字体（JetBrainsMono）负责技术信息；页面叠加极淡的 CRT 扫描线和暗角，但整体干净克制，不堆砌霓虹。

它的气质：**复古硬件终端 × 现代桌面应用**。像一台自带显示屏的调试终端，但动效是丝滑的 Apple 曲线。

---

## 2. 设计原则（生成任何页面都必须遵守）

1. **深底为主，颜色只做强调**。大面积是 `--bg`/`--bg2`，彩色只出现在边框、小标签、关键数据上。切忌彩色铺满。
2. **2px 实线边框 > 圆角**。几乎不用 `border-radius`（最多 2px）；卡片靠"边框 + 内部加深背景"分层，不靠阴影分层。
3. **硬阴影只在交互时出现**。常态无阴影；hover 时 `translateY(-2px)` + `4px 4px 0 rgba(0,0,0,0.4)` 硬阴影（不模糊、不扩散），这是"像素感"的关键。
4. **信息分级靠三档文字色 + 大写像素标签**。正文 `--ink`，次级 `--muted`；小标签一律 `Silkscreen` + `letter-spacing: 1-3px` + `UPPERCASE`。
5. **一切动效用 Apple 曲线**：`--ease-apple: cubic-bezier(0.25,0.1,0.25,1)`。不跳、不弹，除非特意做"像素弹跳"（`--ease-bounce`）。
6. **CRT 扫描线必须极淡**（透明度 ≤ 0.15），否则油腻。它是质感，不是主题。
7. **留白克制**：区块间距 24-48px，内容行高 1.7，容器最大宽 960-1080px 居中。

## 3. 色彩令牌

统一语义命名（各历史文档里的 `--accent/--accent2/--orange/--cyan/--purple` 均映射到下面这套精简版，橙色已移除，强调色收敛为紫色系）：

### 3.1 背景与文字

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#07090F` | 页面底色（近黑蓝） |
| `--bg2` | `#0D1117` | 卡片 / 面板底色 |
| `--bg3` | `#161B22` | 更内层的容器（代码块、标签底） |
| `--bg4` | `#1E2530` | 按压态 / 实心小标签底 |
| `--ink` | `#E8ECF1` | 主文字 |
| `--ink2` | `#C9D1D9` | 次级文字 |
| `--muted` | `#7D8590` | 弱化文字 / 元信息 |
| `--rule` | `#21262D` | 细分隔线 / 默认边框 |
| `--rule2` | `#30363D` | 强调边框 / hover 前状态 |

### 3.2 语义色（强调色，只用于边框、标签、关键数字）

> **本风格刻意做颜色减法**：强调色收敛为单一紫色系，状态色只保留绿/黄/红，**不使用橙色和青色**。

| 令牌 | 值 | 语义 | 典型场景 |
|---|---|---|---|
| `--brand` | `#8B5CF6` | 品牌主色 · 紫 | Hero 标题、区号、主按钮、激活态 |
| `--brand-dim` | `#5B21B6` | 深紫（深底上） | 紫色徽标边框、主按钮 hover |
| `--primary` | `#A78BFA` | 次强调 · 浅紫（同紫系） | 进行中标记、信息 callout、链接 |
| `--primary-dim` | `#6D28D9` | 深紫 | 浅紫徽标边框 |
| `--ai` | `#C4B5FD` | AI 强调 · 淡紫（同紫系） | AI 相关模块、AI 徽标 |
| `--ai-dim` | `#6D28D9` | 深紫 | 淡紫徽标边框 |
| `--success` | `#4ADE80` | 完成 / 安全 · 绿 | 完成态、MVP 必交付、验收通过 |
| `--warn` | `#FACC15` | 警告 / 谨慎 · 黄 | 风险、需确认、MVP 可选（唯一的暖色，仅此一处） |
| `--danger` | `#F87171` | 危险 / 阻塞 · 红 | 高危、已否决、危险操作 |

> 色彩映射说明：本方案从原版 6 个色系（橙/青/紫/绿/黄/红）缩减为 4 个色系（紫/绿/黄/红）。`--brand/--primary/--ai` 三者收敛到紫系的不同亮度层级，视觉上是"一个强调色"。**用色原则**：绿=安全/完成、黄=警告、红=危险/拒绝、紫=品牌/主操作/进行中/信息/AI。主按钮文字用浅色 `#F5F3FF`（紫底上浅字对比度优于深字）。

### 3.3 半透明强调底（徽标、callout、判定框通用）

用 `rgba(色, 0.04~0.15)` 做底色 + 1-2px 实色边框：

```css
/* 例子：绿色徽标 */
.badge-success {
  color: var(--success);
  border: 1px solid var(--success);
  background: rgba(74,222,128,.08);
}
```

## 4. 字体与排版

### 4.1 字体角色（4 个家族，各司其职）

| 变量 | 字体 | 角色 |
|---|---|---|
| `--pixel` | Silkscreen | 像素小标签：版本号、区号、徽标、stamp、状态、小按钮字 |
| `--pixel-body` | PixelifySans | 显示级标题：`.title`、`.sec-title`、Hero logo |
| `--body` | Tektur | 正文字体：正文、卡片描述、h3/h4 |
| `--mono` | JetBrainsMono | 技术信息：代码、表格数值、文件树、元数据、spec 值 |

```css
@font-face { font-family:'Silkscreen';   src:url('./_shared/fonts/Silkscreen-Regular.ttf') format('truetype'); }
@font-face { font-family:'PixelifySans'; src:url('./_shared/fonts/PixelifySans-Medium.ttf') format('truetype'); }
@font-face { font-family:'Tektur';       src:url('./_shared/fonts/Tektur-Regular.ttf') format('truetype'); font-weight:400; }
@font-face { font-family:'Tektur';       src:url('./_shared/fonts/Tektur-Medium.ttf')  format('truetype'); font-weight:500; }
@font-face { font-family:'JetBrainsMono';src:url('./_shared/fonts/JetBrainsMono-Regular.ttf') format('truetype'); }
@font-face { font-family:'JetBrainsMono';src:url('./_shared/fonts/JetBrainsMono-Bold.ttf')   format('truetype'); font-weight:700; }
```

> 若无法随包字体，回退栈：`Silkscreen, monospace` / `Tektur, system-ui, sans-serif` / `JetBrainsMono, ui-monospace, monospace`。**正文回退**：`-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`。

### 4.2 字号阶梯

| 元素 | 字体 | 字号 | 字距 | 风格 |
|---|---|---|---|---|
| Hero logo | pixel-body | 40-80px, 900 | 0.1-0.15em | 品牌色 + 发光脉冲动画 |
| 区号 `.sec-num` | pixel | 24-28px | — | 品牌色 |
| 区标题 `.sec-title` | pixel-body | 22-28px | 1-2px | 主文字色 |
| 段落小标签 `.ver`/`.badge` | pixel | 10-13px | 2-3px | UPPERCASE，muted |
| h3 | body | 16-18px | — | 主文字色，稍重 |
| 正文 | body / system | 14-15px | — | 行高 1.7 |
| 代码 / 技术值 | mono | 12-13px | — | ink2 |

### 4.3 大写像素标签（贯穿全局的"声音"）

所有 10-13px 的小标签：`text-transform: uppercase; letter-spacing: 1-3px; font-family: var(--pixel);`。这是让页面"有灵魂"的关键之一——无论徽标、区 tag、按钮还是版本号，都统一这种写法。

## 8. 动效规则

| 场景 | 曲线 | 时长 |
|---|---|---|
| hover 边框/位移 | `--ease-apple` | 0.2-0.3s |
| 进度条填充 | `--ease-apple` | 0.8s |
| 视图切换 | `--ease-apple` | 0.3s |
| 像素弹跳（趣味） | `--ease-bounce` `cubic-bezier(0.34,1.56,0.64,1)` | 0.3-0.5s |
| 闪烁光标/状态 | `step-end` | 1s 循环 |

硬阴影 hover 统一写法：`transform: translate(-2px,-2px)` 或 `translateY(-2px)` + `box-shadow: var(--shadow-hard)`。

## 9. 反模式（禁止项）

- ❌ 圆角卡片（默认 `border-radius: 0`；最多 2px）。这套风格是"方形像素"，不是毛玻璃。
- ❌ 大面积渐变背景。渐变只允许极淡的光晕（透明度 ≤ .05）。
- ❌ 柔和模糊阴影（`box-shadow: 0 4px 20px`）。要用硬阴影 `4px 4px 0`。
- ❌ 霓虹堆砌 / 颜色超载：强调色只用紫系（brand/primary/ai），状态色只用绿/黄/红。**禁止引入橙色、青色**作为新的强调色；一屏同色系以外出现超过 3 个色系即视为超标。
- ❌ 默认浏览器控件样式：按钮、输入框、滚动条都要自定义成像素风（2px 边框、mono/pixel 字体）。
- ❌ 大段纯 `mono` 正文：mono 只用于技术值、代码、表格、文件树。
- ❌ 文字堆叠无层级：所有小标签记得 UPPERCASE + letter-spacing，标题记得用 pixel-body。
- ❌ 扫描线过浓（透明度 > .15）。
- ❌ 五彩渐变文字（如彩虹渐变标题）。
